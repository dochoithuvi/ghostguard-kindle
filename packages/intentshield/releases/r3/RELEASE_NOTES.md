# DCPRO IntentShield™ 1.0 Final r3

**OneClick + AutoSync** — bản đã được chủ máy xác nhận hoạt động trên Kindle Basic 2022.

- Cài KOReader / ZenOS khi cần, giữ bản đang dùng nếu tương thích.
- Cải thiện ổn định cảm ứng, hiển thị tiến trình cài đặt.
- Tự mở KOReader / ZenOS sau khi cài; tự xóa file OneClick khỏi thư viện khi có thể.
- Tự đồng bộ bản quyền online khi cần, tự bật Global Shield và Auto Resume nếu hợp lệ.
- Auto Boot vẫn là tùy chọn thử nghiệm, không tự bật.

## Cài đặt

Tải **DCPRO_IntentShield_OneClick_Install.sh**, chép vào `documents`, thoát KOReader, kết nối Wi-Fi và chạy bằng SH Integration (root). Xem [README](https://github.com/dochoithuvi/ghostguard-kindle/blob/main/README.md) để biết yêu cầu, thao tác và cứu hộ.

Tương thích mục tiêu: Kindle Basic 2022 jailbreak, KOReader 2026.03+ và ZenOS 4.3+ có cấu trúc phù hợp. Các bản tương lai cần vượt qua kiểm tra tương thích. Không thay đổi khóa ký hoặc registry production.
